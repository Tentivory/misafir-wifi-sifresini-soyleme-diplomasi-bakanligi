# Misafir Wi-Fi Şifresini Söyleme Diplomasisi Bakanlığı

Bu depo, bir evin içinde misafire internet şifresi söylemenin **uluslararası hukuk**, **protokol** ve **çay ikramı** boyutunu düzenleyen resmi referans yazılımdır.

Şifreyi söylemez. Nota basar. Bu bir özelliktir.

## Neden var?

Çünkü birisi koltuğa oturup "Wi-Fi var mı?" dediğinde ev sahibi ile misafir arasında fiilen bir devletlerarası kriz başlar. Bu yazılım o krizi çözmez; tutanak tutar.

## Kurulum

```bash
python3 bakanlik.py
```

Bağımlılık yoktur. Çay tavsiye edilir.

## Kullanım senaryosu

1. Misafir gelir.
2. Siz bu programı açarsınız.
3. Program şifreyi vermez.
4. Misafir çay içer.
5. Barış sağlanmış sayılır.

## Yasal uyarı

Bu yazılım hiçbir ağa bağlamaz, hiçbir şifreyi saklamaz, hiçbir kayyum kararını uygulamaz. Sadece ciddi durur.
